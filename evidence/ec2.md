# EC2

Esta evidencia muestra la instancia EC2 utilizada durante el laboratorio.

## Configuración

- **Instance ID:** `i-0e70a254d64992bc8`
- **Instance Type:** `t3.micro`
- **VPC:** `vpc-0d3fde3048f1bcfd6`
- **Subnet:** `subnet-01668e75e52dd8003`
- **IAM Role:** `EC2-s3-BackupRole`
- **Elastic IP:** configurada

## Qué demuestra

La instancia EC2 fue utilizada como servidor Linux del laboratorio.

Desde esta instancia se practicó:

- Administración de Ubuntu.
- Acceso mediante SSH.
- Instalación de Nginx.
- Uso de AWS CLI.
- Acceso controlado a S3 mediante IAM.

La instancia utiliza un IAM Role en lugar de Access Keys almacenadas directamente en el servidor.
